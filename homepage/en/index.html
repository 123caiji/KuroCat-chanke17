Why KuroCat

Not a static sticker, it reacts to everything you do

Built from native input APIs and real time 2.5D vector physics for coding, gaming, digital illustration, and livestreaming.

Full state keyboard, mouse & 2.5D graphics tablet

Uses IOHIDManager on macOS, Raw Input on Windows, and XInput2 + evdev on Linux. Tracks rapid typing, WASD holds, stylus strokes, 3 key hind foot kicks, and 4 key tail taps.

Raw Input / IOHID Auto Stylus Mode True NKRO

2.5D spherical head tracking & expressive physics

Head, ears, whiskers, and eyes rotate smoothly toward your cursor. Shake fast for wide hunting eyes, pet for purrs, lift by the scruff with 2D inertia, and watch it curl up to sleep at low CPU.

FAQ

Common questions answered clearly

Privacy, Bongo Cat comparison, OBS setup, and OS permissions. Need help with something else? Open a GitHub Issue.

Open GitHub Issue Community 10 Q&A
Does KuroCat record or upload my keystrokes?

No. Every keyboard and mouse event stays strictly in local memory to drive animations and counters. Nothing is logged to disk or uploaded. The entire codebase is MIT open source for public inspection.

How is KuroCat different from classic Bongo Cat?

KuroCat is natively built in Swift, Win32 C++, and GTK3 Cairo (802 KB on Windows) across macOS, Windows, Linux, and UOS, adding 2.5D head tracking, hunting eyes, graphics tablet support, OBS transparent/green modes, 2D scruff drag physics, and an online Skin Workshop.

How do I add KuroCat to OBS Studio or streaming apps?

Right click the cat or tray icon, open Settings, and enable OBS Transparent Window Capture or OBS Green Screen (#00FF00), then add a Window Capture source in OBS. Fullscreen auto hide pauses automatically during OBS capture.

How do I open Settings after enabling full mouse click through?

Click the KuroCat icon in the macOS menu bar or Windows / Linux system tray anytime. You can also hold Option on macOS or press Ctrl + Alt + Shift + P on Windows to toggle menu access.

macOS says unverified developer or keyboard does not respond?

Right click KuroCat.app and pick Open on first run. Then check KuroCat under System Settings → Privacy & Security → Input Monitoring and restart it from the menu bar.

Is the Windows SmartScreen prompt normal?

Yes. Open source indie apps without a paid commercial signing certificate can trigger SmartScreen on new releases. Compare the SHA 256 checksum with GitHub Releases, then click More info → Run anyway.

Does it work on UnionTech UOS and Kylin Linux?

Yes. Linux packages target glibc 2.28 (Debian 10) for both x86_64 and ARM64, supporting UOS 20 and Kylin V10 with both .deb and password free tar.gz installers.

How do I turn my own cat into a custom skin?

Open the KuroCat Skin Workshop in your browser to analyze a cat photo, draw bezier coat regions, add 2.5D sticker accessories, export .kurocat, and drag it right onto your desktop cat.
